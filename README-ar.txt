مشروع XO Arena — موقع إكس أو أونلاين
======================================

المشروع عبارة عن موقع ويب فقط (HTML/CSS/JavaScript) يدعم:
- لعبة محلية على نفس الجهاز.
- إنشاء غرفة بكود من 5 أحرف/أرقام.
- دخول لاعب آخر من شبكة إنترنت مختلفة باستخدام Firebase Realtime Database.
- تصميم متجاوب للموبايل والكمبيوتر.

مهم: اللعب المحلي يعمل فورًا. اللعب أونلاين لن يعمل قبل ربط Firebase.

إعداد Firebase لأول مرة
------------------------
1) افتح https://console.firebase.google.com وأنشئ مشروعًا جديدًا.
2) من Project settings > General أضف Web App وانسخ firebaseConfig.
3) افتح Authentication > Sign-in method، ثم فعّل Anonymous.
4) من Build > Realtime Database أنشئ قاعدة بيانات.
5) انسخ إعدادات Firebase إلى أعلى index.html مكان القيم التي تبدأ بـ PASTE_YOUR_.
   تأكد من databaseURL التي يعطيها Firebase؛ قد تنتهي بـ firebasedatabase.app بدلًا من firebaseio.com.
6) من Realtime Database > Rules استخدم ملف database.rules.json الموجود بالمشروع، ثم اضغط Publish.
7) ارفع index.html إلى GitHub Pages أو أي استضافة HTTPS.

ملاحظات أمنية
-------------
قواعد قاعدة البيانات في هذا المشروع مناسبة كبداية تعليمية فقط: تسمح للمستخدم المسجل دخولًا مجهولًا بقراءة وكتابة بيانات الغرف. لا تستخدمها لمعلومات خاصة أو لعبة تنافسية مهمة؛ يمكن للاعب تقني التلاعب بحالة الغرفة. لمشروع عام، انقل منطق الحركات إلى خادم موثوق واستخدم قواعد تحقق أدق.

تشغيل محلي
----------
افتح index.html أو شغله عبر خادم محلي بسيط. بعض المتصفحات قد تتعامل بشكل أفضل مع ES modules عبر localhost.
